## 与保留 fallback 版的对比

| 指标 | 去掉 fallback（冻结版） | 保留 fallback |
|---|---|---|
| 年化收益 | 8.10% | 14.20% |
| 夏普 | 0.45 | 0.67 |
| 最大回撤 | -54.42% | -54.42% |

| 2019 | 12.76% | 39.99% |
| 2020 | 27.02% | 48.77% |
| 2021–2026 | 不变 | 不变 |

差异集中在 2019/2020 年，说明 fallback 选入的净流入指数贡献了大部分超额收益。去掉 fallback 后主动收益 -1.02%，资金流反转信号本身没有产生超额。
