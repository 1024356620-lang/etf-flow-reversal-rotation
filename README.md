# ETF 资金流反转效应指数轮动策略复现

复现中泰证券金融工程专题报告《指数应用研究系列二：基于ETF资金流反转效应与持有人结构异质性的指数轮动策略》（2026-03-15）。

本项目从 CSMAR 原始数据出发，完成数据清洗、因子构建、样本池筛选、选股、月度回测与绩效评估，并记录了复现过程中遇到的数据工程问题、回测引擎修复过程、账本内部一致性的逐日核验方法、因子前视问题的排查与修复，以及去掉净流出 fallback 后主动收益转负的发现。

---

## 策略逻辑

| 模块 | 规则 |
|---|---|
| 样本池 | 指数上日 ETF 跟踪规模 > 5 亿元，且机构占比 < 70% |
| 因子 | 10 日累计 ETF 资金流强度（份额变动 × 收盘价 / 上日跟踪规模），当日截面分位 `flow_pct` |
| 调仓 | 月度，月初首个交易日收盘（从 `000300` 交易日历取每月首个交易日） |
| 选股 | 剔除资金净流入（`flow_cum > 0`），按 `flow_pct` 从低到高选资金流出最强的指数；候选不足 5 个时不退回全体候选 |
| 目标仓位 | 每个指数目标仓位为账户净资产的 20%；最多持有 5 个指数；宽基不足或候选不足时缺额保留现金 |
| 宽基约束 | 预留 3 个宽基仓位；宽基不足时缺额保留现金，不以其他指数补足；非宽基最多补 2 个 |
| 成本 | 证券权重差近似交易成本，单边 0.1%；现金划转不计费 |

**核心假设**：低机构占比（个人投资者主导）指数的资金流呈现反转效应——个人投资者"追涨杀跌"，资金流出最强的指数未来收益最高。高机构占比指数该效应不显著，因此样本池剔除机构占比 ≥ 70% 的指数。

**因子口径说明**：早期实现用 `to_period('2Q')` + `groupby('half').rank(pct=True)` 计算 `flow_cum_std` 并用于选仓，经截断测试确认存在前视。该列已删除，选仓使用当日截面分位 `flow_pct`。

**fallback 说明**：早期实现当净流出候选不足 5 个时退回全体候选（含净流入指数）。去掉 fallback 后，候选不足时只从净流出候选里选，不足的仓位留现金。这一改动使年化从 14.20% 降至 8.05%，详细对比见"与研报的可能差异"。

## 回测可信度核验

回测引擎已通过独立脚本 `tests/verify_account.py` 逐日复算。**核验范围是账本内部一致性**，不包含原始行情准确性、信号可用时点、宽基分类准确性、因子有效性。

| 核验项 | 结果 |
|---|---|
| `[0]` 每日资产权重 + 现金权重 = 1 | 1719 天全部满足，最大偏差 7.8e-16 |
| `[A]` 上日权重 > 0 的资产当日收益覆盖 | 无缺失、无非有限值；`holdings_returns` 覆盖全部“上日有持仓”的日期 |
| `[B]` `market_ret` = 前一日权重 × 当日收益 | 1719 天（完整账本，含空仓期），最大误差 1.1e-16 |
| `[C]` 权重漂移 `w_t = w_{t-1}(1+r_t)/(1+R_t)`，现金同理 | 非调仓日、调仓日 `old_weights/old_cash`、调仓后 `new_weights/new_cash` 全部满足，含空仓期恒等、清仓/建仓边界 |
| `[D]` 换手（含现金）与成本（只含证券）复算 | 一致；`account` 与 `rebalance_detail` 的 `turnover/cost` 对齐；含空仓分支 |
| `[D2]` `net_ret = market_ret - cost`，`cost = (1+market_ret)×traded_fraction×cost_rate` | 恒等式成立，成本基数换算一致 |
| `[E]` 选仓约束：`n_selected≤5`、`non_broad_n≤2`、宽基不足时 `n_selected≤broad_n+2` | 85 个月全部满足 |

### 前视检查

`tests/check_lookahead.py` 用截断测试检查因子是否使用未来数据：分别用完整数据和截至 T 日的数据计算因子，比较 T 日及以前的取值。5 个截断点（2020-02-14、2021-05-20、2022-08-15、2023-11-15、2025-05-15）的 `flow_cum` 和 `flow_pct` 差异均为 0，脚本返回 0。早期 `flow_cum_std` 在季度中间截断差异 3.8e-2 到 7.9e-2，确认有前视，该列已删除。

### 缺失收益处理

`backtest.py` 不 `fillna(0.0)`，只对实际持仓（`weights.index`）取当日收益，有 NaN 直接 `raise ValueError`，报错信息带日期和代码。“未持仓资产上市前”的缺失不会误报。真实数据上运行未触发缺失，说明持仓期间收益完整。

### 成本口径

采用证券权重差近似交易成本。`traded_fraction` 是证券买卖金额占当日收盘扣费前净资产的比例；`cost = (1+market_ret) × traded_fraction × cost_rate` 换算为占上日净资产的比例，与 `market_ret`、`net_ret` 同基数。`turnover` 含现金，仅用于统计资产配置变化；现金划转不计费。

### 宽基约束与候选不足降仓

预留 3 个宽基仓位，缺额保留现金，不以其他指数补足。回测期内 **17 次宽基不足触发降仓**：宽基 2 个时现金 20%，宽基 1 个时现金 40%，宽基 0 个时候选为空、现金 100%。此外，**净流出候选不足 5 个时不再退回全体候选**，只从净流出候选里选，不足的仓位留现金。这些月份执行了预定降仓规则，不代表约束执行失败。`diagnostics.csv` 记录 `broad_n`、`non_broad_n`、`cash_slots`、`cash_weight_implied`、`broad_shortfall_reason`、`candidate_shortfall`。

## 与研报的可能差异

年化 8.05% vs 研报 16.75%，差距约 8.7 个百分点。以下为**可能影响结果的差异**，尚未做受控实验量化各项贡献，不按影响大小排序：

1. **净流出 fallback 的处理**：研报未明确净流出候选不足 5 个时的处理。本复现去掉 fallback，候选不足时降仓；保留 fallback 的版本（候选不足时退回全体候选，可能选入净流入指数）年化为 14.20%、主动收益 +4.81%。两版差异集中在 2019/2020 年（39.99%→12.38%，48.77%→27.02%），2021–2026 年不变。**按文档报告，取消回退并增加现金配置后，该版本的主动收益变为负值（-1.08%）。这一变化同时涉及现金比例、市场暴露和持仓变化，不能单独证明反转因子无效，也不能证明原收益来自动量；资金净流入也不等同于价格动量。保留为待检验假设，需在相同数据、费用、信号、分类和引擎下做受控对照。**
2. **样本池覆盖**：本复现日均 37 个指数；研报称 2020 年以来有效可投指数始终维持在 40 个以上（研报图表 21）。两者统计期间不同，不能直接比较。样本池较小会减少宽基候选，增加降仓触发频率。
3. **宽基约束实现**：研报未明确宽基不足时的处理。本复现采用"预留 3 个宽基仓位、缺额留现金"的硬约束，17 次触发。历史中间版本（引擎修复过程中）的软约束版年化为 10.67%，**不作为最终受控对照**——它未在冻结引擎、冻结成本口径和冻结分类上重新对齐。
4. **基准口径**：本复现用中证全指（000985）价格指数；研报用万得全A 全收益指数（研报图表 25）。价格指数不含股息再投资，且两个指数成分不同，主动收益不可直接比较。
5. **回测起点**：本复现样本池从 2019-01 开始（2017–2018 年 CSMAR ETF 数据覆盖不足），研报从 2017-01 开始。回测起点不同，比较结果受市场区间影响。

**已撤回的旧结论**：

- 旧版"差距来自数据源限制，非代码问题"不成立——回测引擎曾存在持仓估值被样本池污染、成本覆盖收益、每日重新等权三个 bug。修复后重跑，软约束版年化从 11.51% 变为 10.31%，再经硬约束、成本口径修正、前视修复、去掉 fallback 和交易日历修正后为 8.05%。这些数字对应不同修复阶段，不应混用。
- 旧版"价格指数不含股息，超额被低估 1.5–2%/年"方向说反了——对同一基准，价格指数收益低于全收益指数，策略相对价格指数的超额应该更高，不是被低估。
- 旧版"6/7 个年度方向一致，验证了策略核心逻辑"是弱证据。年度涨跌同向不能区分"策略逻辑有效"和"beta 暴露碰巧同向"。

## 已知局限（后续研究核验范围）

本次账本 PASS 和前视检查通过 **不证明**以下事项成立：

1. **原始行情准确性**：CSMAR 的 ETF 行情、份额、指数行情是否与交易所/Wind 一致，是否存在复权、停牌、退市处理问题。账本内部自洽不能排除源数据错误。
2. **信号可用时点**：`flow_cum` 使用 T 日份额变动，调仓在 T 日收盘。若份额数据为盘后或 T+1 披露，存在前视偏差。需要确认 CSMAR 字段披露时点，或做信号滞后一天的对照测试。
3. **半年度分位标准化口径**：早期 `flow_cum_std` 实现有前视，已删除，选仓改用当日截面分位 `flow_pct`。研报"半年度分位数标准化"的具体口径（过去半年滚动窗口还是自然半年、是否只用截至当日的数据）仍待确认。若研报口径与 `flow_pct` 不同，需重做因子并重跑。
4. **宽基分类准确性**：`_is_broad` 基于 `BROAD_BASE_CODES` 集合与 `SECTOR_KEYWORDS['宽基']` 关键词并集，尚未逐一核对每个指数（尤其 `399975`、`399989` 等边界标的）是否应归为宽基。分类偏差会直接影响宽基约束触发频率和降仓结果。
5. **因子有效性**：去掉 fallback 后年化 8.05%、主动 -1.08%。尚未用 Rank IC、分组收益、同池等权对照检验信号的方向性和稳定性。2022/2023 年亏损 -20.09% / -18.59%，需要区分是宽基约束失效、样本池 beta 拖累，还是信号在熊市失效。

## 后续研究计划

按优先级：

1. **信号可用时点核查**：确认 CSMAR 份额字段披露日期；若为 T+1，做信号滞后一天的对照，比较年化和 2022/2023 年亏损。
2. **半年度分位标准化口径确认**：已删除有前视的 `flow_cum_std`，选仓改用 `flow_pct`。仍需核对研报原文或补充材料，确认"半年度分位数标准化"的具体口径。若研报口径与 `flow_pct` 不同，需重做因子并重跑。
3. **宽基分类核对**：列出 `BROAD_BASE_CODES ∪ SECTOR_KEYWORDS['宽基']` 在 85 个月里出现过的代码，逐一核对分类；重点检查 `399975`、`399989`、`399905`、`399300`、`000905`。
4. **样本池覆盖**：检查 `ETF.csv` 的拟合指数映射是否漏了大量宽基/行业 ETF，`csmar_index_daily_clean.csv` 是否缺失指数行情。目标是以**历史真实覆盖、筛选规则和数据质量**为准，而不是以"接近研报的 200 个"为目标。
5. **因子有效性检验**：这一步需要**新增数据导出**，`holdings_returns.csv` 和 `diagnostics.csv` 不足以完成：
   - `holdings_returns.csv` 只含已选资产，有选择偏差；
   - `diagnostics.csv` 没有全体候选的因子值；
   - 同池等权需要当时整个合格样本池及其后续收益。

   应新增一张**信号日候选表**，每个调仓日一行一指数，字段包括：`trade_date`、`index_code`、`flow_cum`、`flow_pct`、`eligible`（是否在样本池）、`selected`（是否被选中）、`forward_ret_1m`（下月收益）、`signal_available_date`（信号实际可得日期）。基于这张表再做：
   - Rank IC：每个调仓日 `flow_cum` 与 `forward_ret_1m` 的 Spearman 相关，看时序均值和 t 统计量；
   - 分组收益：按 `flow_cum` 分 5 组，看 TOP vs BOTTOM 的下月收益差；
   - 同池等权：用 `eligible=True` 的全部候选等权持有，与策略持仓对比。两者差值**衡量相对同池等权的表现差异**，但需区分现金仓位、宽基约束、风险暴露和交易成本的影响，不能直接归因为"选股能力"。

   检验目的是**预测方向、稳定性及统计不确定性**；单个年度的 IC 变化不足以证明信号失效或排除其他原因。
6. **保留 fallback 版作为对照**：当前冻结版去掉 fallback，年化 8.05%。保留 fallback 版年化 14.20%、主动 +4.81%，但 fallback 选入净流入指数。若要做两版对照，需在相同数据、费用、信号、分类和引擎下重跑两版，README 用表格对比，检验超额来源是反转还是其他因素。

## 运行

### 环境

```bash
pip install -r requirements.txt
```

### 数据准备

将以下 CSMAR 数据文件放入 `raw_data/`（数据有版权，不随仓库分发）：

| 文件 | 内容 | 来源 |
|---|---|---|
| `ETF.csv` | ETF 基本信息（代码、拟合指数、简称、规模） | CSMAR 基金数据库 |
| `FUND_MKT_Quotation*.csv` | ETF 日行情（收盘价、流通份额） | CSMAR 基金市场行情 |
| `csmar_index_daily_clean.csv` | 指数日行情（代码、日期、收盘价） | CSMAR 指数日行情 |
| `Fund_HolderStructure.csv` | ETF 持有人结构（机构占比） | CSMAR 基金持有人结构 |

可选：`wind_all_a.csv`（万得全A 日行情，列名 `trade_date, close`），若存在则优先作为基准。

### 执行

```bash
python src/strategy.py --flow-filter-mode absolute --min-etf-size 5e8
python tests/verify_account.py      # 应输出 PASS
python tests/check_lookahead.py     # 应输出 PASS，返回 0
```

输出：全样本绩效、分年绩效、`results/` 下八张表。

### 测试

```bash
pytest tests/ -v
```

`tests/test_backtest.py` 用合成数据锁死三个回测引擎 bug（调仓日收益被成本覆盖、月内每日重新等权、持仓估值被样本池污染）；`tests/verify_account.py` 用真实账本逐日核验；`tests/check_lookahead.py` 用截断测试检查因子前视，失败时返回非零；`tests/test_pipeline_smoke.py` 用 `tmp_path` 隔离输出，不写真实 `results/`。
