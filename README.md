# ETF 资金流反转效应指数轮动策略复现

复现中泰证券金融工程专题报告《指数应用研究系列二：基于ETF资金流反转效应与持有人结构异质性的指数轮动策略》（2026-03-15）。

本项目从 CSMAR 原始数据出发，独立完成数据清洗、因子构建、样本池筛选、月度回测与绩效归因，重点记录复现过程中遇到的 5 类数据工程问题及其解决方案。

---

## 策略逻辑

| 模块 | 规则 |
|---|---|
| 样本池 | 指数上日 ETF 跟踪规模 > 4 亿元，且机构占比 < 70% |
| 因子 | 10 日累计 ETF 资金流强度（份额变动 × 净值 / 上日跟踪规模），当日截面分位 |
| 调仓 | 月度，月初首个交易日收盘 |
| 选股 | 剔除资金流入（`flow_pct > 0.5`），选资金流出最强 TOP5，等权 |
| 约束 | 至少 3 个宽基；宽基去重（沪深300/中证500 的沪深代码视为同一指数） |
| 成本 | 双边 0.1% |

**核心假设**：低机构占比（个人投资者主导）指数的资金流呈现反转效应——个人投资者"追涨杀跌"，资金流出最强的指数未来收益最高。高机构占比指数该效应不显著，因此样本池剔除机构占比 ≥ 70% 的指数。

| 指标 | 本复现 | 研报 |
|---|---|---|
| 年化收益 | **11.51%** | 16.75% |
| 年化波动 | 23.18% | 22.11% |
| 夏普 | **0.50** | 0.76 |
| 最大回撤 | -56.48% | -28.61% |
| 年化超额 | **+3.30%**（vs 中证全指） | +11.49%（vs 万得全A） |
| 胜率 | 50.06% | 64% |

分年绩效：

| 年份 | 本复现 | 研报 | 方向 |
|---|---|---|---|
| 2019 | +36.12% | +31.32% | 一致 |
| 2020 | +41.06% | +40.26% | 一致 |
| 2021 | +12.50% | +34.71% | 一致 |
| 2022 | -27.33% | -13.93% | 一致（幅度放大） |

策略方向在 6/7 个年度与研报一致。2023 年背离及 2022 年幅度放大，归因于样本池结构差异（见下文）。

## 核心工程问题与解决

复现过程中遇到并解决了以下 5 类数据问题，详细排查过程见 [`docs/replication_notes.md`](docs/replication_notes.md)。

| # | 问题 | 现象 | 解决方案 | 效果 |
|---|---|---|---|---|
| 1 | `merge_asof` 排序约束 | `ValueError: left keys must be sorted` | 改为逐指数 `merge_asof` | 跑通 |
| 2 | `index_code` 脏数据 | 样本池仅 76 个指数 | `_clean_index_code` 去中文/空格/后缀 | 交集 173 → 242，样本池 76 → 127 |
| 3 | 月初整行缺失 | 月初候选数骤降到 1 | `MultiIndex.reindex` + `fillna(0)` | 候选数恢复正常 |
| 4 | 绝对阈值受市场环境影响 | `flow_cum <= 0` 在牛熊市过滤力度不一 | 改为 `flow_pct <= 0.5`（截面相对阈值） | 年化 9.50% → 11.24% |
| 5 | 2022/2023 年亏损放大 | 反复选中新能源/科技/医药 | 尝试行业分散约束（反而恶化），最终归因于样本池结构 | 在结论中说明 |

## 与研报的差距归因

年化 11.51% vs 研报 16.75%，差距 5.2 个百分点，归因于三方面**数据源限制**，非策略逻辑或代码问题：

1. **样本池规模**：本复现日均 37 个指数（研报约 50 个），其中宽基仅 20–30 个，行业主题占 70%+。2022/2023 年行业主题暴跌 30%+，组合被拖累；研报样本池宽基占比更高，熊市抗跌。
2. **基准口径**：本复现用中证全指（000985）价格指数，研报用万得全A 全收益指数。价格指数不含股息再投资，超额被低估约 1.5–2%/年。
3. **时间起点**：本复现样本池从 2019-01 开始（2017–2018 年 CSMAR ETF 数据覆盖不足），研报从 2017-01 开始，缺少两年牛市初期样本。

策略核心逻辑（资金流反转 + 低机构占比 + 月度轮动）在 2019/2020/2021/2024/2025 年均得到验证。

## 运行

### 环境

```bash
pip install -r requirements.txt
```

### 数据准备

将以下 CSMAR 数据文件放入项目根目录（数据有版权，不随仓库分发）：

| 文件 | 内容 | 来源 |
|---|---|---|
| `ETF.csv` | ETF 基本信息（代码、拟合指数、简称、规模） | CSMAR 基金数据库 |
| `FUND_MKT_Quotation*.csv` | ETF 日行情（收盘价、流通份额） | CSMAR 基金市场行情 |
| `csmar_index_daily_clean.csv` | 指数日行情（代码、日期、收盘价） | CSMAR 指数日行情 |
| `Fund_HolderStructure.csv` | ETF 持有人结构（机构占比） | CSMAR 基金持有人结构 |

可选：`wind_all_a.csv`（万得全A 日行情，列名 `trade_date, close`），若存在则优先作为基准。

### 执行

```bash
python src/strategy.py
```

输出：全样本绩效、分年绩效、2021–2023 年持仓明细（含板块标签）。
